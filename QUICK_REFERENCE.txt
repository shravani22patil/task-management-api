🚀 QUICK START
──────────────
1. pip install -r requirements.txt
2. python main.py
3. Open http://localhost:8000/docs (Swagger UI)
4. Test endpoints directly in browser

📍 ENDPOINTS
────────────
GET    /tasks              → List all tasks
GET    /tasks/{id}         → Get single task
POST   /tasks              → Create task
PUT    /tasks/{id}         → Update task
DELETE /tasks/{id}         → Delete task
GET    /stats              → Get statistics
GET    /health             → Health check

💻 QUICK CURL TESTS
────────────────────
# Get all tasks
curl http://localhost:8000/tasks

# Create task
curl -X POST http://localhost:8000/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"Buy milk","description":"2 liters"}'

# Update task (mark as done)
curl -X PUT http://localhost:8000/tasks/1 \
  -H "Content-Type: application/json" \
  -d '{"done":true}'

# Delete task
curl -X DELETE http://localhost:8000/tasks/1

# Get stats
curl http://localhost:8000/stats

🌐 WEB INTERFACES
──────────────────
Swagger UI:  http://localhost:8000/docs      (best for testing)
ReDoc:       http://localhost:8000/redoc     (nice documentation)
HTML UI:     Open index.html in browser      (interactive dashboard)

📊 STATUS CODES
────────────────
200 → Success (read/update)
201 → Created (POST successful)
204 → Deleted (DELETE successful)
400 → Bad request (invalid input)
404 → Not found (resource doesn't exist)

📝 HTTP METHODS
────────────────
GET    → Retrieve data (safe, no side effects)
POST   → Create new resource
PUT    → Update existing resource
DELETE → Remove resource

🔍 QUERY PARAMETERS
─────────────────────
/tasks?done=true        → Get completed tasks
/tasks?search=milk      → Search in titles
/tasks?limit=10         → Limit results
/tasks?offset=20        → Skip first 20

🐛 TROUBLESHOOTING
────────────────────
Port already in use?
  → uvicorn main:app --port 8001

Module not found?
  → pip install -r requirements.txt

Can't connect to API?
  → Check server is running (python main.py)
  → Check firewall isn't blocking port 8000

Web UI can't connect?
  → Ensure localhost:8000 is the API base URL
  → Check browser console for errors
